# chinese-vernacular

一个写给 AI 用的中文写作 skill：先按真人写作的流程把文章写出来，再把它洗到看不出 AI 痕迹。

它不是润色工具，也不是检测器。它是一套流程加两份规则清单，交给一个能读写文件的 agent 执行。

## 解决什么问题

- 论证发散：模型按语义相关性铺陈，不按逻辑推进，排比成串，结尾自我否定。
- 语体错位：单双音节搭配失当，「钱怎么稳」这种口号体混进叙述和口播。
- 节奏均匀：句长一致，段落等长，主位复读，全篇一个声调。
- 符号残留：破折号当连接号，正文里带 markdown 符号，公式写成 LaTeX 上下标。
- 高频模板：不仅更是、值得注意的是、不是而是、综上所述这类安全句式。

## 工作流

六个阶段，每个阶段都产出文件，不靠记忆接力：

1. 拆分单元。成品由几块能独立成文的部分组成时，一块一个文件。不能拆就整篇一个文件。
2. 构思。写清写作主题、论据清单、事实黑名单、文风，并判定语体与结构档位。
3. 提纲。排段落序列，写段落节拍表。
4. 逐段写作。每段走三步：段前定观点与起点，写作时守配平规则，段后跑七项自查。
5. 子代理去 AI 味。扫描脚本生成点评稿，子代理在副本上改，原稿不动。
6. 终审与汇总。朗读、重复、结构、模板、符号、标点六项过一遍，再按用户要求的格式合并交付。

所有中间文件放在成品同目录的 `<成品名>_work/` 里：

| 文件 | 用途 |
| --- | --- |
| `构思与提纲.md` | 所有单元按节记录构思与提纲 |
| `01-单元名.md` | 单元正文，编号即拼接顺序 |
| `01-单元名_review.md` | 脚本生成的点评稿，正文里穿插点评块 |
| `01-单元名_edit.md` | 原稿的干净副本，子代理在这里改，改完就是成品单元 |

## 目录结构

```
.
├── SKILL.md                 写作流程与全部规则，交给 agent 读
├── references/
│   ├── 句式黑名单.md        十一类句式模板与处理动作
│   └── 上下标字符表.md      Unicode 上下标对照
├── scripts/
│   └── detect_patterns.py   句式扫描，产出点评稿与待改副本
└── target.md                测试用样本稿
```

## 安装

把整个目录放进所用 agent 的 skills 目录，例如：

```
~/.claude/skills/chinese-vernacular/
```

SKILL.md 的 frontmatter 已经是标准格式：`name` 与目录同名，`description` 写清用途与触发场景。

## 使用

让 agent 读 SKILL.md 之后照做即可。一个典型请求：

```
用 chinese-vernacular 帮我写一篇关于远程办公的评论，两千字左右。
```

流程会自己在成品目录建 `_work/` 文件夹，逐单元推进，最后合并。

如果手上已经有稿子，只想去 AI 味，可以直接走第五步：

```
python scripts\detect_patterns.py 稿件.md
```

会生成两个文件：

- `稿件_review.md`：正文每段后面插入点评块，格式是 `> 【AI句式：分类名】具体句式`，后接命中片段、可疑点、建议方向、保留条件。
- `稿件_edit.md`：原稿的干净副本，供改写。

把这两个文件和原稿一起交给子代理，提示词模板在 SKILL.md 第四段。

### 脚本参数

```
python scripts\detect_patterns.py <文件> [--min-hits 2] [--out 路径] [--report]
```

- `--min-hits`：同一类命中几次才报出，默认 2。单次出现按规则压掉，只列位置。
- `--out`：点评稿路径，默认同目录 `<文件名>_review.md`。
- `--report`：另把 Markdown 报告打到终端，调试用。

扫描前会跳过 frontmatter、围栏代码块、行内代码和引用块。原稿永不被改写；待改副本如果已经被改过，再次运行脚本不会覆盖它。

## 规则与维护

脚本的九类规则写在 `scripts/detect_patterns.py` 的 `RULES` 里，每条包含触发正则、可疑点、建议方向、保留条件。句式黑名单是它的文字版，两边要同步改：

- 加规则：先在黑名单对应小节加一行「句式 ｜ 处理动作」，再在脚本里补一条。
- 改措辞：建议方向以黑名单为准，脚本照抄。
- 黑名单第七类（评价性空壳）和第十一类（排版层）不参与扫描，前者是词汇层，后者归符号规则。

## 已知限制

- 扫描是召回，不是判决。命中只说明可疑，改不改由模型按保留条件判断，误报在所难免。
- 只做句型匹配，不碰标点、markdown 符号和排版，那些归 SKILL.md 第三段的符号规则。
- 专有名词、术语、产品名、数据口径的一致性优先于多样性，重复不算模板。
- 子代理必须能读写文件。没有子代理的环境，退回主代理按同一份提示词自查。
