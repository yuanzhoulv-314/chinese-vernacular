# 句式黑名单

这些句式的共同点，是用姿态替代信息。判据只有一条：把这句话原样搬到另一篇文章里仍然成立，它就是模板。

## 改写策略

改的时候优先换一种写法，不是只删。删完不补内容，句子会变成空壳，比原来更差。五个动作按顺序试：

1. 具体化。把评价换成可核对的动作、数量、时间、地点。写「快」不如写「三小时的活压到二十分钟」。
2. 梯度化。把并列改成有落差的推进：前一项给条件，后一项给后果或代价。递进靠事实的落差，不靠「更」字。
3. 条件化。把免责对冲改写成适用条件，前置到主张里。什么条件下成立，什么条件下不成立，一次说清。
4. 换视角。把说话人的评价换成别人能看见的动作：谁、在什么场合、做了什么。
5. 换结构。编号换成关系词承接，排比换成长短句，总起句直接删掉进入内容。

## 一 伪递进与伪升华

| 句式 | 处理动作 |
| --- | --- |
| 不仅…更…、不仅…还… | 后项写成前项的具体后果或代价，数值、时间、损失任选其一 |
| 不仅是…更是… | 后项落到可验证的变化：谁、什么时候、变了多少 |
| 不只是…而是… | 先给前项一个具体场景，再写后项的动作，否定面全篇只留一次 |
| 真正值得关注的是… | 直接写那件事，把「为什么值得」放进后面的事实里 |
| 真正值得X的、最值得X的 | 删评价词，直接把那件事说出来 |
| 值得注意的是、值得一提的是、需要注意的是 | 删引导词；确要提示，换成「这里有个反常识的地方」，后面必须真反常识 |
| 更重要的是、更关键的是、最核心的是 | 删排序词，后项写成前项的推进：由此、于是、落到具体处 |
| 这背后是、本质上、归根结底 | 写机制链：谁做了什么，导致什么，读者能顺着查 |
| 离不开… | 写成依赖条件：没有甲就没有乙，一次讲清 |
| 体现了、彰显了、印证了、折射出 | 删盖章；确要留，换成第三方能看见的动作 |
| 标志着…、奠定了…基础 | 换成日期加事件加后续影响 |
| 从…到…，从…到… | 保留一个跨度，把中间怎么变的写出来 |
| 为…提供了新的思路、新的可能 | 写具体可做的一件事，能照着做的才算 |
| 打开了…的大门、开启了新篇章 | 删，或写后续的实际动作 |
| 让…成为可能 | 写谁在什么时候做成了什么 |
| 从某种意义上说、在某种程度上 | 换成明确条件：在什么情况下 |
| 这并非偶然、绝非偶然 | 给出原因，或写「这不是第一次」再加一件事实 |
| 更根本的一层、更深一层 | 用递进承接：再往下、还要往里、最难的是、最后落到 |

## 二 空转转折与伪对立

| 句式 | 处理动作 |
| --- | --- |
| 不是…而是… | 先写前项的一个具体表现，再写后项的动作；全篇否定面对比只留一处 |
| 不是…，是…（省略式） | 同上；或改成时间对比：以前怎样，现在怎样 |
| 不在…而在… | 前面用事实铺垫，后面直接写修正后的判断，省掉否定句 |
| 与其说…不如说… | 只留后一种说法，前一种降成一句事实前提 |
| 然而真正的问题是、但问题在于 | 先看前文有没有立靶子。没有就删转折直接说；有就写「这个解释有个漏洞」再接事实 |
| 问题在于、关键在于 | 写成卡在哪：具体环节加后果 |
| 表面上…实际上… | 只写实际那层，前面用一次具体观察代替「表面上」 |
| 看似…实则… | 用两个事实对照，不加「看似」这类提示词 |
| 一边是…一边是… | 用具体主体替换「一边」，或改成前后两段的对照 |
| 与其…不如… | 留建议，把被否掉的那个选择写成一句事实 |

## 三 免责收束与过度对冲（除非用户要求辩证看待）

| 句式 | 处理动作 |
| --- | --- |
| 当然，…也不一定 | 把适用条件前置：在甲情况下成立，在乙情况下不成立 |
| 但也得承认另一面 | 两面写成两个条件，各给一条事实，不要写成回撤 |
| 否则…站不住 | 删掉自我辩护，判断硬不硬由正文承担 |
| 因人而异、各有利弊、见仁见智 | 给分界：偏好甲的人看什么，偏好乙的人看什么 |
| 需要指出的是、客观来说、客观地看 | 删引导语，直接说那条事实 |
| 但这并不意味着、这不等同于 | 删；确有被误读的风险，写成「这只说明甲，不说明乙」，全篇一次 |
| 不能单凭此事认定、不应将其理解为 | 同上，把边界写进条件句 |
| 仍须谨慎解读、有待进一步研究 | 写出具体缺口：样本多大、观察多久、缺哪一环 |
| 最终还需要实际验证 | 删；要留就写清验证什么、谁来验证 |
| 在一定程度上、某种程度上 | 删，或把程度写实：三成、多数、个别 |
| 仅供参考、以实际情况为准 | 删 |

## 四 机械序列与路标

| 句式 | 处理动作 |
| --- | --- |
| 首先…其次…最后 | 换成关系词承接：先…接着…最要紧的是…；或用时间、因果串起来 |
| 第一…第二…第三（正文内） | 同上；确要分点，放到排版层面，正文里不念编号 |
| 第X层、第X点 | 用递进短语承接：再往下、更要紧的是、最难的是、最后落到；或拿上一段结尾的名词做下一段起点 |
| 让我们、接下来我们、话不多说 | 删，直接上内容 |
| 以下是你需要知道的、几个关键点 | 删，直接给内容 |
| 在开始之前、在此之前需要说明 | 删；确需前置条件，写成一句条件 |
| 综上、总而言之、总的来说、一句话总结 | 删，停在最后一条事实；长文可写「回到开头那个问题」 |
| 到这里，我们已经… | 删 |
| 说到底、归根到底 | 删这层壳，把结论连同依据一起写出来 |

## 五 时代背景开场

| 句式 | 处理动作 |
| --- | --- |
| 随着…的不断发展、日益普及 | 从一个具体事件、数字或场景起笔 |
| 在…的今天、在这个时代 | 删，写年份或事件 |
| 当今社会、如今…已经成为 | 换成某年某地发生了什么 |
| 这是一个…的时代 | 删，用一件事实代替定性 |
| 你有没有发现、你是否曾经 | 直接陈述，或先给一个能看见的场景 |

## 六 万能收尾

| 句式 | 处理动作 |
| --- | --- |
| 未来可期、拭目以待、值得期待 | 删；确有下一步，写清时间与动作 |
| 让我们共同…、携手… | 删 |
| 希望这篇文章对你有所帮助、有所启发 | 删 |
| 总之，…是…的关键 | 删，把结论提前写进正文 |
| 任重道远、道路还很长 | 删，写出具体难在哪一处 |
| 以上就是…的全部内容 | 删 |
| 欢迎留言、你怎么看、点赞关注 | 删，用户要做互动才留 |

## 七 评价性空壳

| 句式 | 处理动作 |
| --- | --- |
| 赋能、抓手、闭环、落地、颗粒度、底层逻辑、组合拳 | 换成动作加对象加结果 |
| 深度融合、全面赋能、持续发力 | 写清谁和谁、怎么合、合完怎样 |
| 打造…体系、构建…矩阵 | 列出包含哪几样，各自解决什么 |
| 具有重要意义、发挥了重要作用 | 写影响到谁、多久、多少 |
| 备受关注、广受好评、引发热议 | 给出处加时间，引一句原话 |
| 可谓、堪称、不失为 | 删，直接下判断 |
| 毫无疑问、毋庸置疑、不容否认 | 删 |
| 深刻影响、深远意义 | 写具体变化：价格、数量、时间 |

## 八 排比与对偶

| 句式 | 处理动作 |
| --- | --- |
| 三连排比 | 留两项，第三项改成具体例子；或把三项改成递进，前后有落差 |
| 连续的字短语排比 | 砍到两项，或改成一长一短的散句，把其中一项展开成半句 |
| 既是…也是…、既要…又要… | 留一边，另一边写成它成立的条件 |
| 没有…没有…没有… | 留一项，其余换成具体细节 |
| 短句连击（一句一顿） | 合并成一句，用逗号接 |
| 自问自答 | 删问句，把答案写成事实 |
| 排比叠递进 | 只留递进那一层，排比部分改成具体 |

## 九 句式壳子与翻译腔

| 句式 | 处理动作 |
| --- | --- |
| 作为…，… | 删「作为」，直接说身份或动作 |
| 被视为、被认为、被广泛认为 | 写明谁、在什么场合说的 |
| 对…进行分析、作出调整、加以说明 | 换实义动词 |
| 在…方面、在…层面、在…维度上 | 删，或写具体环节 |
| 基于…的… | 写条件 |
| 通过…来…、借助…实现… | 还原成主谓宾 |
| 使得…得以… | 换「让」 |
| 具有…的特征、有…的必要 | 换成直言 |

## 十 元话语

| 句式 | 处理动作 |
| --- | --- |
| 本文将、下面我们从…说起 | 删 |
| 正如前面所说、如前所述 | 删；要回指就用名词短语点一下那件事 |
| 简单来说、换句话说、也就是说 | 全篇留一次；用的时候必须真换一个角度 |
| 有人可能会说、你可能会问 | 删；真要回应异议，把异议的具体内容写出来 |
| 顺便提一句、多说一句 | 删 |

## 十一 排版层

| 句式 | 处理动作 |
| --- | --- |
| 加粗关键句成瘾 | 加粗只留数据与结论 |
| 小标题三级编号 | 砍到一级 |
| 破折号插入语连用 | 拆句 |
| 引号强调 | 引号只给反讽、引文、专名 |
| 每段凑三点 | 按信息量分点，一条也行 |

## 使用提醒

- 表里的句式真人也在用，单次出现不是问题，密度才是。同一类模板在一篇里出现两次以上再动手。
- 命中先做整句搬迁测试，能搬到别的文章里，说明它是壳。
- 删完要补具体信息，否则句子会空。
- 同一个比喻或同一组四字格连用三次以上，收掉两次。
