# 句式黑名单

这些句式的共同点，是用姿态替代信息。判据只有一条：把这句话原样搬到另一篇文章里仍然成立，它就是模板。

## 共性

1. 只有姿态，没有信息。宣称重要、宣称递进、宣称转折，删掉之后事实一个不少。
2. 永远站中间。两边都夸，两边都免责，谁也没得罪。
3. 位置固定。段首承接，段中列举，段尾收束，换个话题照样填得进去。
4. 靠对称取信。成对、成三出现，工整本身被当成说服力。
5. 可替换。抽掉句中关键词换成别的，句式依然通顺，说明它是空壳。

## 一 伪递进与伪升华

| 句式 | 处理动作 |
| --- | --- |
| 不仅…更…、不仅…还… | 留后项，前项降成一句前提 |
| 不仅是…更是… | 两句压成一句，只留递进后的那个判断 |
| 不只是…而是… | 先判对立是否真实，假对立删前项 |
| 真正值得关注的是… | 直接写那件事，删掉“真正” |
| 真正值得X的、最值得X的 | 删掉评价词，直接给事实 |
| 更根本的一层、更深一层 | 删掉层级词，直接写这一层说的新东西 |
| 值得注意的是、值得一提的是、需要注意的是 | 删引导词，让事实自己说话 |
| 更重要的是、更关键的是、最核心的是 | 删，靠段落顺序体现轻重 |
| 这背后是、本质上、归根结底 | 写具体机制，不写“本质” |
| 离不开… | 写清谁在支撑，删“离不开” |
| 体现了、彰显了、印证了、折射出 | 整句删除，事实不需要盖章 |
| 标志着…、奠定了…基础 | 换成日期加动作 |
| 从…到…，从…到… | 点名一个具体跨度，删排比 |
| 为…提供了新的思路、新的可能 | 写具体可做的动作 |
| 打开了…的大门、开启了新篇章 | 删 |
| 让…成为可能 | 写谁在什么时候做成了什么 |
| 从某种意义上说、在某种程度上 | 删，或者直接写出限定条件 |
| 这并非偶然、绝非偶然 | 给出原因，删掉感叹 |

## 二 空转转折与伪对立

| 句式 | 处理动作 |
| --- | --- |
| 不是…而是… | 写A的具体表现再写B，否定面全篇最多一次 |
| 不是…，是…（省略式） | 补出真正的转折关系，或者只留后项 |
| 不在…而在… | 只保留修正后的判断 |
| 与其说…不如说… | 只留结论 |
| 然而真正的问题是、但问题在于 | 删转折，直接说问题 |
| 问题在于、关键在于 | 直接陈述卡点，砍掉“在于”这层壳 |
| 表面上…实际上… | 只写实际，表面那层没有用就删 |
| 看似…实则… | 同上 |
| 一边是…一边是… | 用具体主体替换“一边” |
| 与其…不如… | 只留建议 |

## 三 免责收束与过度对冲（除非用户要求辩证看待）

| 句式 | 处理动作 |
| --- | --- |
| 当然，…也不一定 | 删，适用条件写进前提 |
| 但也得承认另一面 | 删掉回撤，或者把两面写成两个条件 |
| 否则…站不住 | 删掉这句自我辩护，判断硬不硬由正文承担 |
| 因人而异、各有利弊、见仁见智 | 选边并给条件 |
| 需要指出的是、客观来说、客观地看 | 删引导语 |
| 但这并不意味着、这不等同于 | 删，前文确有被误读的风险才保留 |
| 不能单凭此事认定、不应将其理解为 | 同上 |
| 仍须谨慎解读、有待进一步研究 | 删，或者写出具体缺口 |
| 最终还需要实际验证 | 任务本身不是评估，整句删 |
| 在一定程度上、某种程度上（与或许叠加） | 限定词只留一个 |
| 仅供参考、以实际情况为准 | 删 |

## 四 机械序列与路标

| 句式 | 处理动作 |
| --- | --- |
| 首先…其次…最后 | 用时间或因果承接，删编号 |
| 第一…第二…第三（正文内） | 改成分段，段落自己证明顺序 |
| 第X层、第X点 | 改成分段，用关系词承接，删编号 |
| 让我们、接下来我们、话不多说 | 删，直接上内容 |
| 以下是你需要知道的、几个关键点 | 删，直接给内容 |
| 在开始之前、在此之前需要说明 | 删 |
| 综上、总而言之、总的来说、一句话总结 | 删，停在最后一条事实 |
| 到这里，我们已经… | 删 |

## 五 时代背景开场

| 句式 | 处理动作 |
| --- | --- |
| 随着…的不断发展、日益普及 | 从一个具体事件或数字起笔 |
| 在…的今天、在这个时代 | 删 |
| 当今社会、如今…已经成为 | 换成某年某月发生了什么 |
| 这是一个…的时代 | 删 |
| 你有没有发现、你是否曾经 | 改成直接陈述 |

## 六 万能收尾

| 句式 | 处理动作 |
| --- | --- |
| 未来可期、拭目以待、值得期待 | 删，停在最后一件事实 |
| 让我们共同…、携手… | 删 |
| 希望这篇文章对你有所帮助、有所启发 | 删 |
| 总之，…是…的关键 | 删，结论写进正文 |
| 任重道远、道路还很长 | 删 |
| 以上就是…的全部内容 | 删 |
| 欢迎留言、你怎么看、点赞关注 | 删，用户要做互动才留 |

## 七 评价性空壳

| 句式 | 处理动作 |
| --- | --- |
| 赋能、抓手、闭环、落地、颗粒度、底层逻辑、组合拳 | 换成动作加对象 |
| 深度融合、全面赋能、持续发力 | 写清做了什么 |
| 打造…体系、构建…矩阵 | 写清包含哪几样东西 |
| 备受关注、广受好评、引发热议 | 给出处与时间 |
| 可谓、堪称、不失为 | 删，直接下判断 |
| 毫无疑问、毋庸置疑、不容否认 | 删 |
| 深刻影响、深远意义 | 写出具体变化 |

## 八 排比与对偶

| 句式 | 处理动作 |
| --- | --- |
| 三连排比 | 两项优于三项，删最弱的一项 |
| 连续的字短语排比 | 砍到两项，或者改成一长一短的散句 |
| 既是…也是…、既要…又要… | 保留成立的那一边 |
| 没有…没有…没有… | 留一项，其余删 |
| 短句连击（一句一顿） | 恢复成一个完整句子 |
| 自问自答 | 删问句，只留答 |
| 排比叠递进 | 只留递进 |

## 九 句式壳子与翻译腔

| 句式 | 处理动作 |
| --- | --- |
| 作为…，… | 删“作为”，直接说身份 |
| 被视为、被认为、被广泛认为 | 写明谁认为，或者删 |
| 对…进行分析、作出调整、加以说明 | 换实义动词 |
| 在…方面、在…层面、在…维度上 | 删，或者写具体环节 |
| 基于…的… | 写条件和动作 |
| 通过…来…、借助…实现… | 还原成主谓宾 |
| 使得…得以… | 换“让” |
| 具有…的特征、有…的必要 | 换成直言 |

## 十 元话语

| 句式 | 处理动作 |
| --- | --- |
| 本文将、下面我们从…说起 | 删 |
| 正如前面所说、如前所述 | 删 |
| 说到底、归根到底 | 删掉这层壳，直接写结论和依据 |
| 简单来说、换句话说、也就是说 | 全篇留一次 |
| 有人可能会说、你可能会问 | 删，除非真在回应异议 |
| 顺便提一句、多说一句 | 删 |

## 十一 排版层

| 句式             | 处理动作                 |
| ---------------- | ------------------------ |
| 加粗关键句成瘾   | 加粗只留数据与结论       |
| 小标题三级编号   | 砍到一级                 |
| 破折号插入语连用 | 拆句                     |
| 引号强调         | 引号只给反讽、引文、专名 |
| 每段凑三点       | 按信息量分点，一条也行   |

## 使用提醒

- 表里的句式真人也在用，单次出现不是问题，密度才是。同一类模板在一篇里出现两次以上再动手。
- 如果命中的句子完全言之无物，可被整句搬到任何文章而无错误则直接删除。
- 拆掉模板之后不允许统一换另一套口吻。统一装口语、故意断句、堆口头禅是不被允许的。
