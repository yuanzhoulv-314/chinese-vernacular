# 上下标字符表

正文需要角标时，复制这里的字符直接用，例如 A₁、x²、CO₂、m³。不要写成 A_1、x^2、$x^{2}$。

## 缺口处理

如果通过符号无法达成理想的表达效果（如用户表示无法渲染成功，或者需要的字符不存在），则按顺序试三种下位代替：换成中文说法（q 的二次方），换成同义表达（平方代替 ²），把角标改成正文里的并列说明。三种都走不通时保持原样并且告知用户。

## 希腊字母

| 组别 | 字符 |
| --- | --- |
| 上标 | ᵅ ᵝ ᵞ ᵟ ᵋ ᶿ ᶲ ᵡ |
| 下标 | ᵦ ᵧ ᵨ ᵩ ᵪ |

希腊字母的覆盖最不全，用之前先在目标平台看一眼。

## 常见组合

| 写法 | 效果 |
| --- | --- |
| A₁、A₂、Aₙ | 序号角标 |
| x²、x³、y⁴ | 幂次 |
| CO₂、H₂O、O₂ | 化学式 |
| m³、cm² | 单位 |
| 10⁸、2ⁿ | 数量级与指数 |
| a₁b₁ + a₂b₂ | 带序号的变量 |

## 使用提醒

- 同一篇里只用一种角标写法，混用两种比用错更显眼。
